# PWA Icons

Please add the following icon files to this directory for PWA support:

- `icon-192x192.png` - 192x192 pixels icon
- `icon-512x512.png` - 512x512 pixels icon

You can generate these icons from your logo using online tools like:
- https://www.pwabuilder.com/imageGenerator
- https://realfavicongenerator.net/

For development, you can use placeholder icons from:
- https://via.placeholder.com/192x192
- https://via.placeholder.com/512x512
